# Практическая работа: Экспорт и импорт данных в PostgreSQL

## 🎯 Цель работы
Научиться экспортировать и импортировать данные в PostgreSQL с помощью утилиты pg_dump.

## 📋 Задание
1. Создать таблицу Skillbox, заполнить тремя строками и сделать экспорт через pg_dump.
2. Создать базу данных imp и импортировать в неё данные из экспорта.

## 🛠️ Использованные инструменты
- PostgreSQL
- pg_dump — утилита экспорта
- psql — утилита импорта
- SQL: CREATE TABLE, INSERT, SELECT, CREATE DATABASE
- Мета-команды psql: \c

## 📦 Файлы

- [task1.sql](task1.sql) — команды создания таблицы, заполнения и вызова pg_dump
- [task2.sql](task2.sql) — команды создания БД imp и импорта данных

## 📸 Задание 1. Создание таблицы и выгрузка данных

### Команды

-- Выполняется от имени суперпользователя postgres

-- DDL-команда: создание таблицы
CREATE TABLE Skillbox (
  col1 text
);

-- DML-команды: вставка трёх строк
INSERT INTO Skillbox (col1) VALUES ('Первый текст');
INSERT INTO Skillbox (col1) VALUES ('Второй текст');
INSERT INTO Skillbox (col1) VALUES ('Третий текст');

-- Проверка (необязательно)
SELECT * FROM Skillbox;

-- Сохраняем изменения
COMMIT;

-- Экспорт данных таблицы Skillbox с помощью pg_dump
pg_dump -U postgres -h localhost -d postgres -t Skillbox -f skillbox_export.sql

### Пояснения

| Команда | Что делает |
|---------|------------|
| CREATE TABLE Skillbox | Создаёт таблицу с одним столбцом col1 типа text |
| INSERT INTO Skillbox | Добавляет 3 строки с текстовыми данными |
| SELECT * FROM Skillbox | Проверяет, что данные добавлены |
| COMMIT | Фиксирует транзакцию |

### Разбор pg_dump

pg_dump -U postgres -h localhost -d postgres -t Skillbox -f skillbox_export.sql

| Параметр | Значение | Назначение |
|----------|----------|------------|
| -U | postgres | Пользователь для подключения |
| -h | localhost | Хост БД |
| -d | postgres | Имя базы данных |
| -t | Skillbox | Имя таблицы (только её экспортируем) |
| -f | skillbox_export.sql | Файл, куда сохраняется дамп |

Без параметра -t был бы экспортирован весь дамп базы данных. С -t выгружается только таблица Skillbox.

## 📸 Задание 2. Импорт данных в новую таблицу

### Команды

-- Выполняется от имени суперпользователя postgres

-- 1. Создание новой базы данных imp
CREATE DATABASE imp;

-- 2. Импорт данных из файла экспорта
-- (выполняется из терминала, не внутри psql)
psql -U postgres -h localhost -d imp -f skillbox_export.sql

-- 3. Проверка наличия данных в таблице Skillbox
\c imp
SELECT * FROM Skillbox;

### Пояснения

| Команда | Что делает |
|---------|------------|
| CREATE DATABASE imp | Создаёт новую БД imp |
| psql -U postgres -h localhost -d imp -f skillbox_export.sql | Импортирует данные из дампа в БД imp |
| \c imp | Переключает psql на базу imp |
| SELECT * FROM Skillbox | Проверяет, что данные импортированы |

### Разбор команды psql

psql -U postgres -h localhost -d imp -f skillbox_export.sql

| Параметр | Значение | Назначение |
|----------|----------|------------|
| -U | postgres | Пользователь для подключения |
| -h | localhost | Хост БД |
| -d | imp | База данных, в которую импортируем |
| -f | skillbox_export.sql | Файл с дампом |

Команда импорта выполняется из терминала, а не внутри psql. Она подключается к БД imp и выполняет все команды из файла skillbox_export.sql — то есть создаёт таблицу Skillbox и вставляет в неё три строки.

### Проверка

После импорта:
- \c imp — переключение на БД imp
- SELECT * FROM Skillbox — вывод трёх строк: «Первый текст», «Второй текст», «Третий текст»

Это подтверждает, что экспорт и импорт прошли корректно.

## 🔐 Практическая значимость
Навыки экспорта и импорта данных критичны для администратора БД и специалиста по ИБ:
- резервное копирование отдельных таблиц и БД;
- перенос данных между серверами (миграция);
- восстановление данных после сбоев;
- аудит и анализ данных в изолированной среде;
- безопасное хранение бэкапов.

В реальной работе pg_dump — основной инструмент для создания логических бэкапов PostgreSQL. Понимание его параметров позволяет гибко управлять резервным копированием: от одной таблицы до всей базы.

## ⚠️ Особенности выполнения
- Параметр -t Skillbox в pg_dump экспортирует только одну таблицу. Если убрать -t, будет выгружена вся база postgres.
- Команда psql -f выполняется из терминала, а не внутри интерактивной сессии psql. Это важно: внутри psql такой синтаксис не работает.
- Мета-команда \c imp — это команда psql, а не SQL. Она переключает текущую БД в интерактивной сессии.
- Файл skillbox_export.sql содержит и DDL (CREATE TABLE), и DML (INSERT) — поэтому при импорте таблица создаётся заново в новой БД.
- COMMIT при autocommit не обязателен, но полезен для явной фиксации.
